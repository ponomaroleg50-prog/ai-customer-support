# AI Customer Support

> **Статус: Concept / Planned — проектная концепция, не готовое приложение.**

## Бизнес-задача
Повторяющиеся вопросы клиентов перегружают поддержку и увеличивают время ответа.

## Цель и бизнес-ценность
Создать инструмент, который решает указанную задачу и позволяет оценивать эффект внедрения на согласованных показателях.

## Предполагаемый стек
OpenAI API (Responses API), Python/FastAPI, база знаний, REST API, CRM/webhooks (планируемые компоненты).

## Функциональные блоки (план)
1. Приём обращений из сайта или мессенджера
2. Поиск релевантной информации в проверенной базе знаний
3. Генерация ответов с ограничениями и отказом от неподтверждённых фактов
4. Передача сложных запросов оператору
5. Журналирование, аналитика и оценка качества

## Предполагаемая архитектура
Пользовательский канал → серверная логика и проверки → OpenAI/поиск/интеграции → ответ пользователю или передача сотруднику. Конкретная архитектура будет уточнена после сбора требований.

## План реализации
1. Согласовать FAQ, каналы и KPI с заказчиком
2. Собрать прототип с тестовой базой знаний
3. Настроить передачу оператору и интеграции
4. Проверить безопасность, точность и стоимость
5. Развернуть пилот и измерить результат

## Критерии оценки результата
Доля корректных ответов, время первого ответа, процент эскалаций, стоимость обработки обращения.

## Скриншоты и демонстрация
Пока отсутствуют: интерфейс и код ещё не реализованы. После разработки здесь появятся реальные скриншоты, схема архитектуры и ссылка на демонстрацию.

## Запуск
На текущем этапе **запуск невозможен**: исходный код и конфигурация ещё не опубликованы. После реализации будут добавлены зависимости, пример `.env.example`, команды установки и запуска. Секреты и API-ключи не должны попадать в репозиторий.

## Безопасность
Планируются минимизация персональных данных, контроль доступа, защита API-ключей, тестирование на prompt injection и контроль расходов API.
